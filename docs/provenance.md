# Project provenance

Samsung TV Launcher is a source snapshot derived from [Quiet Tizen](https://github.com/jss8649/quiet-tizen/tree/cf518d7a9278dca7990e27756218258e44044a29), commit `cf518d7a9278dca7990e27756218258e44044a29`. That project's MIT license and third-party notices are retained. Its original U8000F research is preserved in [upstream provenance](upstream-provenance.md) and the existing upstream observation/profile files; those results are not S90D results.

This project's additions include four dinosaur theme sets, a native theme picker with bounded active-theme image caching, atomic preference persistence, six app shortcuts, a stock Samsung Home escape route, S90D-specific access gating, a native Home/startup helper with drift/readback guards, privacy-focused publication checks, and S90D verification/recovery documentation. The redundant top-right Apps/Inputs/Settings buttons were removed; equivalent functions remain in primary navigation.

Theme backgrounds and tile illustrations were made with the built-in OpenAI ImageGen tool. They were exported as local PNG resources, split into independent app tiles, resized for the native renderer, and stripped of nonvisual metadata for publication. The published themes contain no device screenshots or household identifiers. App labels, clock, focus rings and menus remain native UI. Sources/prompts are documented in [theme art](themes.md), without conversation transcripts or private machine paths.

The temporary archive-root access subset originates in [samsung-tv-root](https://github.com/chris-ritsen/samsung-tv-root/tree/4ad2c4d3b0d0e0da4b5b7ebe4a787e94596f416b), commit `4ad2c4d3b0d0e0da4b5b7ebe4a787e94596f416b`, Unlicense. Quiet Tizen's runtime fallback is retained. This project also fixes script transfer decoding in `tools/tv.py` and permits a separately reviewed identity profile. It does not bundle model-specific kernel exploits, firmware keys, continuous controllers, Samsung SDK tools or stock binaries.

Free My TV's earlier design inspiration, Quiet Inter/Inter fonts and Material Symbols retain the notices in [NOTICE.md](../NOTICE.md) and [licenses](../licenses/). The new pixel font is Press Start 2P, distributed under its SIL Open Font License. Related [S90D research in Couchroot](https://github.com/splitcipher/couchroot/blob/main/docs/lab/devices/s90d/README.md) informed use of native setters that preserve Buxton key privileges; no owner-specific state from that project is used.

Only the [verification summary](verification.md) describes this project's hardware evidence. Build/test logs, raw sessions, original app files, account/registry databases, exact network configuration, recovery archives and proprietary references remain private and are not part of this repository or its Git history.
